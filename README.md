## v2.1.0 更新说明

### 首页卡片
- 移除首页折线图、收藏标签和收藏星标,只保留 60 格色条
- 卡片重新排版:上传/下载速率与剩余天数/剩余价值同行
- 名称行:系统和国旗图标在左,价格和在线天数在右
- 节点价格为 0 或留空时显示"免费",剩余价值显示"无"
- 剩余时间超过 3650 天显示"长期"
- 节点离线时,离线信息显示在信息行内,不再遮挡
- 流量与硬盘模块位置对调
- 修复 mini 卡片:CPU、内存、流量、硬盘四项同一行均分

### 延迟与丢包
- 悬停提示简化为一行(`18:03  80ms` / `18:05  丢包`)
- 丢包率最多显示两位数字

### 详情页
- 自定义概览卡片 keys 为空时不显示任何概览卡片
- 去掉"运行时间"和"厂商"模块
- 系统信息:竖屏下操作系统与内核版本同一行
- "存储信息"改名为"内存信息"
- 横屏布局:硬件信息在左,系统信息与内存信息在右
- IP 地址独立成"IP地址"模块,IPv6 一行显示完整
- "网络速率"改为"累计上传 / 下载",删除总流量旁"近一天峰值"

### 主题设置
- 删除首页右上角的设置按钮和面板(统一在后台设置)
- 设置项重新分为 9 组:基础设置、背景设置、壁纸设置、公告设置、概览卡片、地球设置、分组设置、多线路设置、详情页设置,并去掉序号
- 分组设置:"显示快捷按钮""列表模式信息栏",厂商自定义别名放在其上方
- 背景相关选项改称"壁纸"
- 移除"自定义站点图标"(后台已有此设置)
