## v2.1.1 更新内容

### 首页卡片
- 延迟与丢包统一为按线路显示的合并 60 格色条，移除延迟、丢包分开两段的旧样式
- 普通卡片默认显示全部线路，线路数量不限；mini 卡片显示第 1 条线路
- 首页延迟改为接口提供的 1 小时平均值（取整），丢包为 60 次探测平均值
- mini 卡片：流量与硬盘位置对调（CPU、内存、硬盘、流量）
- mini 卡片：流量数字去掉空格，与内存、硬盘格式一致（如 69.9GB/2TB）
- 总览卡片的剩余时间大于 3650 天时显示“长期”；流量显示为 `75.7 GB / 2 TB`

### 详情页
- 模块调整：硬件 / 系统 / 内存（含硬盘）/ 流量 / IP；流量模块新增实时网速
- IP 模块 IPv4 与 IPv6 同行显示，仅有单栈时自适应，竖屏字体放大
- 延迟与负载页时间选项统一为：1 小时 / 6 小时 / 1 天 / 7 天 / 30 天 / 自定义
- 延迟页卡片的延迟、丢包使用接口平均值；延迟为整数，丢包最多两位数字
- 延迟页移除“i”详情按钮及“平滑峰值”功能
- 延迟卡片与折线图之间增加间距，不再贴边
- 监控曲线与负载图使用真实时间轴，缺测区间保留断点，不再连续绘制或显示为零
- 切换时间区间时保留已选线路
- 数据不足 30 天或 7 天时，负载图从有数据的日期开始显示

### 主题设置
- 移除“多线路设置”整组，多线路显示改为默认启用
- 设置项重新分组：基础 / 背景 / 壁纸 / 公告 / 概览卡片 / 地球 / 分组 / 多线路 / 详情页，并统一命名（总览卡片 


## v2.1.0 更新说明

### 首页卡片
- 移除首页折线图、收藏标签和收藏星标,只保留 60 格色条
- 卡片重新排版:上传/下载速率与剩余天数/剩余价值同行
- 名称行:系统和国旗图标在左,价格和在线天数在右
- 节点价格为 0 或留空时显示"免费",剩余价值显示"无"
- 剩余时间超过 3650 天显示"长期"
- 节点离线时,离线信息显示在信息行内,不再遮挡
- 流量与硬盘模块位置对调
- 修复 mini 卡片:CPU、内存、流量、硬盘四项同一行均分

### 延迟与丢包
- 悬停提示简化为一行(`18:03  80ms` / `18:05  丢包`)
- 丢包率最多显示两位数字

### 详情页
- 自定义概览卡片 keys 为空时不显示任何概览卡片
- 去掉"运行时间"和"厂商"模块
- 系统信息:竖屏下操作系统与内核版本同一行
- "存储信息"改名为"内存信息"
- 横屏布局:硬件信息在左,系统信息与内存信息在右
- IP 地址独立成"IP地址"模块,IPv6 一行显示完整
- "网络速率"改为"累计上传 / 下载",删除总流量旁"近一天峰值"

### 主题设置
- 删除首页右上角的设置按钮和面板(统一在后台设置)
- 设置项重新分为 9 组:基础设置、背景设置、壁纸设置、公告设置、概览卡片、地球设置、分组设置、多线路设置、详情页设置,并去掉序号
- 分组设置:"显示快捷按钮""列表模式信息栏",厂商自定义别名放在其上方
- 背景相关选项改称"壁纸"
- 移除"自定义站点图标"(后台已有此设置)
